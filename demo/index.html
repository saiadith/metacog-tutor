With metacognitive layer metacog

How it decides: each message is classified as answer-seeking, explanation, verification, planning or off-task. Two answer-seeking turns with no own attempt trigger a planning nudge; a verification request gets a monitoring nudge; after a full solution, more requests trigger argue-back (critique a flawed solution) or teach-back (explain it to a confused peer). Nudges have a cooldown and a cap of 3 per problem, so the AI never blocks help. Replies here are scripted for the demo; the real study app calls an LLM and logs everything for analysis.
